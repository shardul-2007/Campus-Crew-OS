    Citizens

    End users accessing CivicOS via any modern browser. The interface is responsive, accessible and works on all screen sizes — no app install required.

    CivicOS Interface — React + Vite

    Why React? Component-based architecture for reusable civic UI panels — maps, dashboards, status cards. Rich state management with hooks. Fast iteration via HMR.

    Why Vite? Near-instant HMR, optimized production builds. Significantly faster than Create React App for complex projects.

    Component strategy: Page-level components consume shared data hooks. Map, analytics and reporting panels are independent modules assembled at the route level.

    AI Intelligence Layer

    Purpose: Surface intelligent insights from civic data — classifications, natural language queries, automated summaries.

    Input: Civic data streams, citizen requests, geographic context.

    Output: Processed insights, recommendations and smart search results shown inline in the UI.

    Maps — Leaflet 1.9.4

    Why Leaflet? Lightweight (~42KB gzipped). No API key or billing. Open-source with OpenStreetMap tiles. React-Leaflet wrapper integrates cleanly with the component model. Google Maps would add SDK overhead and usage limits.

    Interactive markers, clustered pins for dense data, click-to-inspect for location details.

    Analytics — Recharts

    Why Recharts? Built natively for React — no DOM conflicts. Declarative chart composition. Responsive SVG. Chosen over Chart.js for cleaner React integration and smaller footprint for the specific chart types needed.

    Civic APIs — REST

    Data flow: External civic sources → API layer → application state → UI components.

    Error handling: Graceful degradation — API failures show cached data or honest empty states, never a crash.

    Caching: Responses cached with TTL-based invalidation for time-sensitive civic data.

    Problem

    Citizens lack a unified intelligent interface for municipal services. Information is scattered across disconnected portals — making civic engagement cumbersome and unintuitive.

    Solution

    CivicOS aggregates civic data into a unified platform with AI intelligence, interactive maps and real-time analytics — making municipal information accessible and actionable.

    My Role

    Full-stack development — frontend architecture, AI integration, map and analytics implementation, responsive design, and deployment on Vercel.

    What Broke → What I Learned

    Problem

    Initial API integration caused high latency — the map felt sluggish and unresponsive on first load.

    Attempt

    Added request caching, loading states, and optimistic UI updates to hide latency.

    Result

    Perceived performance improved significantly. Map interactions became snappy with cached baseline data.

    03ENGINEERING

    How I Build

    Architecture decisions, performance principles, technical thinking — and a running build log.

    Separation of concerns

    UI, data and logic stay cleanly separated. In CivicOS: React components handle rendering, custom hooks manage state and fetching, API modules handle external communication. Each layer is independently testable and replaceable.

    Composition over inheritance

    Smaller, focused components assembled into complex UIs rather than deep hierarchies. CivicOS's map, analytics and reporting panels are independent modules composed at the page level.

    Graceful degradation

    Every external dependency has a fallback. If an API fails, the UI shows a meaningful empty state. This portfolio works without GitHub API, AI, or any external service — core content is always statically available.

    ReactCivicOS

    Component-based for reusable civic UI. Rich state management with hooks. Fast iteration. Chosen over vanilla JS for CivicOS's complexity — interactive data panels benefit from the component model.

    ViteCivicOS

    Near-instant HMR during development. Optimized production builds with automatic code-splitting. Significantly faster than CRA — important when iterating on complex map-heavy UI.

    Leaflet 1.9.4CivicOS

    ~42KB gzipped. No API key or billing. Open-source. React-Leaflet integrates cleanly with the component model. Google Maps would add SDK overhead and usage limit complexity.

    RechartsCivicOS

    Native React charting — no DOM conflicts. Declarative chart composition. Responsive SVG. Cleaner React integration than Chart.js for the specific chart types CivicOS needs.

    Plain HTML/CSS/JSThis Portfolio

    Zero build step. GitHub Pages compatible. Fast to iterate. CSS custom properties handle the entire design system. The right tool for a content-focused site with no complex state.

    Animation: GPU-only properties

    All animations use transform and opacity only — no layout-triggering properties. Scroll progress uses transform: scaleX(). Canvas draws are paused via IntersectionObserver when off-screen.

    JS: passive listeners + rAF

    All scroll/resize listeners use passive: true. Canvas draws run inside requestAnimationFrame. IntersectionObserver replaces scroll event listeners for reveal animations.

    Assets + fonts

    Profile image has explicit width and height to prevent CLS. Non-hero images use loading="lazy". Inter loaded with display=swap to avoid render blocking. No heavy libraries loaded without a genuine reason.

    Semantic HTML first

    Every element uses the correct semantic tag — <header>, <nav>, <main>, <section>, <article>. Heading hierarchy is always correct (one <h1>, logical nesting). Landmark roles are clearly defined.

    Full keyboard navigation

    Every interactive element is reachable by keyboard. Command palette has arrow-key navigation, Enter to execute, Escape to close. Modals trap focus correctly. Shortcuts (1–7, /, G) don't interfere with input fields.

    Motion safety

    prefers-reduced-motion: reduce disables all animations — boot sequence skips instantly, constellation is static, word rotator stops, canvas disabled. Content and functionality are identical.

    This portfolio — GitHub Pages

    Deployed from main branch of shardul-2007/my-portfolio. Push to main → live in ~60 seconds. Zero-cost, zero-config, global CDN.

    CivicOS — Vercel

    Deployed on Vercel for React/Vite optimization, automatic preview deployments on PRs, and global edge network. Zero-configuration detection for Vite projects makes the deployment workflow frictionless.
